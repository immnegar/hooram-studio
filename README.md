# استودیو خلاق هورام (Hooram Studio)
### وب‌سایت استودیو نوآوری و تبلیغات مبتنی بر هوش مصنوعی (AI Creative & Advertising Studio)

این پروژه یک وب‌سایت شرکتی مدرن، فوق‌العاده سریع و ماژولار است که به‌طور اختصاصی برای یک استودیو خلاقیت و تبلیغات مبتنی بر هوش مصنوعی در ایران طراحی و پیاده‌سازی شده است.

---

## ۱. ویژگی‌ها و صفحات پیاده‌سازی شده

### بخش عمومی وب‌سایت (Public Facing):
1. **صفحه اصلی (Home - `/`)**:
   - هدر شیشه‌ای (Glassmorphic) ریسپانسیو با لوگو و برندینگ هورام.
   - بخش قهرمان (Hero) با هدلاین فارسی جذاب، افکت نوری محیطی، آمار شاخص (کاهش ۸۰٪ هزینه‌ها، تحویل ۷ روزه، خروجی 4K سینمایی).
   - ویترین آثار برگزیده با برچسب مشخص «کانسپت استودیو» و کارت‌های تعاملی.
   - بخش تشریح ۳ رکن اصلی خدمات استودیو.
   - بخش تمایز هورام (چرا استودیو هورام؟).
   - نقشه راه ۵ مرحله‌ای فرآیند خلق اثر.
   - بنر فراخوان نهایی (CTA) برای ثبت استعلام پروژه.
   - فوتر جامع با اطلاعات تماس دفتر تهران، زمان پاسخگویی و پیوندها.
2. **صفحه خدمات (Services - `/services`)**:
   - دسته‌بندی کامل خدمات سه‌گانه:
     - **بخش A**: تولید تیزر و ویدیوهای تبلیغاتی هوش مصنوعی (AI Commercials, Product Commercials, Social Ads)
     - **بخش B**: طراحی و توسعه وب‌سایت‌های مدرن (Corporate, E-commerce, Landing Pages)
     - **بخش C**: تبلیغات و کمپین‌های خلاق هوش مصنوعی (Key Visuals, Storyboards, 360 Campaigns)
   - مزایا، ابزارها و مدل‌های هوش مصنوعی (Runway Gen-3, Midjourney, Claude, DaVinci).
   - بخش پرسش‌های متداول (FAQ) کارفرمایان پیرامون کپی‌رایت و ثبات چهره.
3. **گالری نمونه‌کارها (Portfolio - `/portfolio`)**:
   - فیلتر بر اساس ۴ دسته‌بندی اصلی.
   - جستجوی بلادرنگ در عناوین، برندها و توضیحات.
   - نشانگر پخش ویدیو و برچسب تفکیک کانسپت‌های استودیویی.
4. **صفحه جزئیات پروژه (Project Case Study - `/portfolio/:slug`)**:
   - پخش‌کننده ویدیویی یا تصویری بزرگ پروژه.
   - گالری تصاویر جانبی تعاملی.
   - جدول اطلاعات پروژه (کارفرما، سال تولید، دسته‌بندی، مدت زمان).
   - تشریح صورت مسئله و چالش کارفرما.
   - راهکار هوش مصنوعی و هنر کارگردانی استودیو.
   - ابزارها و مدل‌های به‌کار رفته.
   - اقلام تحویل داده شده.
   - ناوبری میان پروژه‌های قبلی و بعدی.
5. **درباره ما و مانیفست استودیو (About Us - `/about`)**:
   - مانیفست استودیو: چرا هورام صرفاً یک اپراتور هوش مصنوعی نیست؟
   - فلسفه نام‌گذاری هورام (ریشه فارسی و نماد روشنایی و نشاط).
   - چهار ستون هویت کاری و ساختار تیمی متخصصان.
6. **فرآیند ۵ مرحله‌ای تولید (Our Process - `/process`)**:
   - از بریفینگ استراتژیک، سناریو و استوری‌بورد تا تولید ژنراتیو، تدوین سینمایی و تحویل چندرسانه‌ای.
7. **فرم ثبت استعلام و لید جنریشن (Contact - `/contact`)**:
   - دریافت نام، نام شرکت/برند، شماره تماس معتبر (با اعتبارسنجی ارقام ایرانی)، ایمیل، خدمت درخواستی، بودجه تخمینی، شرح پروژه و لینک رفرنس.
   - ذخیره‌سازی بلادرنگ در دیتابیس پایدار و نمایش کد رهگیری استعلام به کاربر.

### پنل مدیریت استودیو (Protected Admin Dashboard):
- **ورود ایمن مدیر (`/admin/login`)**: احراز هویت با JWT و اعتبارسنجی رمزنگاری‌شده (Bcrypt).
- **پیشخوان و آمار (`/admin`)**: شاخص‌های کلیدی عملکرد (کل استعلام‌ها، لیدهای جدید، مذاکرات در جریان، تعداد پروژه‌ها).
- **مدیریت استعلام‌ها (`/admin/inquiries`)**:
   - فیلتر وضعیت‌ها: جدید (New)، در حال بررسی (Under Review)، تماس گرفته شد (Contacted)، مذاکره و پیش‌پروپوزال (Negotiation)، تبدیل به قرارداد (Converted to Project)، آرشیو شده (Archived).
   - تغییر آنی وضعیت هر لید در دیتابیس.
   - مشاهده کامل بریف و نیازهای کارفرما در مودال اختصاصی.
   - ثبت و ذخیره یادداشت‌های داخلی استودیو برای هر لید.
   - امکان حذف استعلام.
- **مدیریت نمونه‌کارها (`/admin/portfolio`)**:
   - افزودن پروژه جدید همراه با تصاویر، ویدیو، اقلام تحویلی و ابزارها.
   - ویرایش پروژه‌های موجود.
   - فعال/غیرفعال‌سازی نمایش در بخش آثار برگزیده صفحه اصلی.
   - حذف پروژه با تأییدیه.
- **مدیریت خدمات (`/admin/services`)**:
   - ویرایش عناوین، توضیحات و تکنولوژی‌های هر دسته خدماتی.

## ۲. معماری فنی و پایداری برای بازار ایران

در انتخاب استک فنی، محدودیت‌های اینترنت و تحریم‌ها/فیلترینگ‌های دوطرفه در ایران به دقت مد نظر قرار گرفت:

1. **Frontend**:
   - **React 19 + TypeScript**: توسعه فوق‌العاده ماژولار و تایپ‌سیف.
   - **Vite 6**: سریع‌ترین باندلر با بیلد بهینه‌سازی شده زیر ۱.۳ ثانیه.
   - **Tailwind CSS v3**: طراحی تم تاریک استودیویی (Dark Luxury Aesthetic)، تایپوگرافی فونت وزیرمتن فارسی و چیدمان ۱۰۰٪ راست‌به‌چپ (RTL).
   - **Lucide Icons**: آیکون‌های برداری سبک و مینیمال بدون وابستگی به CDNهای فیلترشده.
2. **Backend & Database**:
   - **Node.js + Express**: سازگار با تمام ارائه‌دهندگان میزبانی و سرورهای داخلی ابری در ایران (هام‌روش، لیارا، ابر آروان، پارس‌پک، سرورهای لینوکس ایران).
   - **Persistent File/JSON Engine با Atomic Writes**: بدون نیاز به راه‌اندازی دیتابیس‌های پیچیده خارجی یا اتکا به سرویس‌های ابری خارجی مانند فایربیس یا سوپابیس (که از هر دو طرف تحریم یا دچار نوسان DNS در ایران هستند). اطلاعات با کش در حافظه و نوشتن امن و اتمیک ذخیره می‌شوند.
   - **JWT Auth & Bcrypt**: امنیت کامل مسیرهای ادمین و رمزنگاری رمز عبور.

## ۳. نحوه راه‌اندازی و اجرای پروژه

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm

### گام‌ها:
```bash
# رفتن به پوشه پروژه
cd "C:\Users\Saraye Tel\.gemini\antigravity\scratch\hooram-studio"

# اجرای همزمان سرور API و محیط توسعه فرانت‌اند:
npm run dev

# یا ساخت نسخه نهایی پروداکشن و اجرا روی تک‌پورت 5000:
npm run build
npm start
```

پس از اجرا:
- وب‌سایت اصلی: `http://localhost:5000` (یا در حالت توسعه فرانت‌اند `http://localhost:3000`)
- پنل مدیریت: `http://localhost:5000/admin`

## ۴. راه‌اندازی و اطلاعات ورود به پنل مدیریت

- **آدرس ورود**: `http://localhost:5000/admin/login`
- **ایمیل**: طبق تنظیمات محیطی `ADMIN_EMAIL` یا مقدار فایل دیتابیس
- **رمز عبور**: طبق متغیر محیطی `ADMIN_DEFAULT_PASSWORD` (در دیتابیس نمونه: `changeme123` که در اولین ورود باید تغییر یابد)
*(توصیه می‌شود بلافاصله پس از راه‌اندازی اولیه، از بخش تنظیمات پیشخوان اقدام به تغییر رمز عبور نمایید)*
